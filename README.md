### Exercise 2 – Git Bisect Bug Hunt (Simulation)

For this exercise, I reviewed my GitHub commit history to simulate how git bisect finds the commit where a problem was introduced.  
The commit **“Introduced bug statement (for Git Bisect simulation)”** represented the version containing the issue.  
By checking earlier commits, I could see when the correct text last appeared and where it changed.  
This shows how git bisect can locate the exact commit that introduced an error without testing every version manually.

### Exercise 3 – Group Practice Reflection

In this exercise, our group practiced resolving merge conflicts and collaborating through GitHub.  
Each member worked on their own branch and made changes to shared files like Visuals.md and Source material.md.  
When two branches edited the same line, GitHub showed a merge conflict, and we had to fix it manually by deciding which version to keep.

This activity helped me understand:
- How to handle conflicts when several people edit the same file.  
- How to use pull requests and branches effectively.  
- The importance of writing clear commit messages and communicating with teammates.  

The most challenging part was remembering to set the correct base branch and keeping track of which branch I was working on.  
After completing this, I feel more confident working on group projects using GitHub.
